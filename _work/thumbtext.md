## Project Details

**Venue:** Graphics Interface (GI) 2018  
**Type:** Peer-reviewed Conference Paper  
**Role:** Researcher, Interaction Designer, Prototype Developer

## Overview

How can users efficiently enter text on extremely small wearable devices?

ThumbText explored text entry using a ring-sized touch surface operated by the thumb. The project investigated interaction techniques that could support practical text input despite severe space constraints.

## My Role

- Researcher
- Interaction Designer
- Prototype Developer
- Study Designer

## Problem

Wearable devices often provide limited screen space, making traditional text-entry methods slow and error-prone. The goal of this project was to design an input technique specifically for a miniature ring-based interface.

## Methods

The project involved multiple stages:

- Exploration of touch-surface layouts
- Iterative interaction design
- Prototype development
- Controlled user studies
- Comparative evaluation against existing wearable text-entry techniques

## Key Findings

- A 2×3 grid layout provided effective thumb-based input on a ring-sized surface.
- Continuous touch-slide-lift interactions outperformed several alternative selection techniques.
- Participants achieved faster text-entry rates than comparable wearable text-entry methods.
- Users were able to transfer learned skills across different wearable display types.

## Outcome

The project produced ThumbText, a novel text-entry technique for wearable devices, and demonstrated that efficient text input is possible even on extremely small touch surfaces.

## Skills Demonstrated

Interaction Design · Prototyping · User Studies · Experimental Design · Quantitative Evaluation · Wearable Computing · Human-Computer Interaction

## Reflection

One of the most interesting design challenges was balancing input capacity and usability on an extremely constrained surface. The project reinforced the importance of iterative prototyping and empirical evaluation when designing novel interaction techniques.
